# Pane 便签 MVP 技术方案

本文细化[功能对齐清单](notes-parity-checklist.md)，是设计稿。以本机 Galaxy Tools `6156e93` 为交互参照，继续使用 Pane 的 WinUI、窗口材质、主题和字体。纯文本编辑、TXT 文件操作、整条便签提醒及完整胶囊系统随同一个 MVP 交付。下文的技术验证和手测可以分步进行。

**术语。** 下文区分三个概念，不再使用含义不明的「固定」：

- **贴到桌面**：便签有桌面窗口或胶囊入口。对应现有 `IsNotePinned`（`DesktopNotes` 中有该 ID），属于本机布局。
- **窗口置顶**：桌面便签窗口保持在其他窗口之上。对应现有 `DesktopNoteTopmost`，属于本机布局，与是否贴到桌面相互独立。
- **列表排序**：管理器中的顺序。MVP 不另设「列表置顶」字段；如果对照确认 Galaxy 有此能力，再作为正文以外的显示偏好补充。

正文、布局和提醒通过便签 ID 关联，职责分开。编辑正文会更新正文修改时间；拖动、窗口置顶、折叠或设置提醒不改正文时间，也不制造历史版本。布局只存显示偏好及几何，不写入正文；纯展示窗口不自行写数据。

不做旧便签、旧附件或旧布局迁移。实现及验收使用新数据目录；不编写启动时清理已有数据的流程。Pane 其他模块的 Markdown 组件保持原用途。

但升级后的 Pane 仍可能打开原有目录，因此读取规则要明确：

- 旧记录中的 `Images` 和 `EditorMode` 读取时忽略，正文按纯文本显示。下次正文提交写出 MVP 模型后，这两个字段不再保留。
- 移除现有的便签图片清理逻辑，`.images` 目录原样保留，不被读取，也不进入备份。
- 设置里的 `NoteTaskReminders` 不再调度，也不弹窗；整条便签提醒照常生效。

## 2. 纯文本编辑与跨窗口同步

管理器目前使用 `NoteStore.Draft`，桌面走独立的 `SaveCardEdit`。MVP 收敛为一个按便签 ID 索引的编辑会话：标题、正文、分类、当前修订号、最近成功写盘的修订号，以及保存状态。管理器选中哪条是视图状态，切换选中项不会改变其他便签的草稿。

1. 用户输入先在 UI 线程更新共享草稿，广播便签 ID、修订号和来源。其他已打开视图立即更新；同一窗口的程序赋值不再回发，避免循环和光标跳动。胶囊只订阅其需要的标题或预览内容。
2. 自动保存按便签合并短时间内的连续输入。同一 ID 的写入串行；写入使用当时的快照。如果写盘期间又有输入，旧成功结果只推进已保存修订，不替换新草稿，后续保存接着提交最新快照。
3. 显式保存、折叠、隐藏、关闭、切换以及历史恢复复用同一保存入口。需要交接时等待对应草稿写盘；失败保留当前输入与窗口，显示失败并允许重试。最后一个视图关闭后，只有已经保存的会话才可释放。程序退出时先保存所有未写盘的会话；仍有失败时提示并允许取消退出。系统注销或关机无法等待时，把未保存草稿写入数据目录下的恢复文件，下次启动提示用户恢复或丢弃。
4. 管理器和桌面沿用原生文本框，保留选择、换行、复制粘贴、撤销重做。中文输入法未提交的组合串由原窗口管理，提交后才同步；接收更新时尽量保留有效选区。撤销产生一次新的共享草稿更新。
5. 导入、新建等操作创建独立的新会话，不再像现在的 `ImportFile` 那样，因当前选中项有未保存修改而拒绝执行。
6. 新建后标题和正文始终为空（只含空白也算空）的会话不写盘。关闭、折叠或切走时直接丢弃，不进回收站，不生成胶囊，也不留布局；已有内容的便签被清空后按普通修改保存。

移除便签专用的 Markdown 切换、工具栏、分栏、渲染、任务操作和图片入口。Markdown 符号按普通字符显示及保存。验收重点是交替输入不丢字、写盘失败不关窗、晚到的保存结果不覆盖更新内容。

## 3. 入口、列表、分类和 TXT

| 功能 | 技术方案与验收 |
| --- | --- |
| 管理器、快速新建、贴到桌面 | 接入 Pane 现有命令路由。管理器只打开一个；快速新建生成新 ID；贴到桌面按 ID 创建或聚焦，重复触发不复制便签。管理器、托盘、行菜单和窗口菜单调用同一组命令。快速新建的落点（新桌面便签还是管理器新条目）以对照 Galaxy 的结果为准，只定一处，不同时打开两处；新窗口取得焦点，光标在正文。托盘另提供「显示全部桌面便签」，展开所有已隐藏但仍贴到桌面的便签。 |
| 快捷键 | 对照 Galaxy 命令清单、窗口处理器及实际绑定，把动作、默认键和作用范围放进同一核对表。Pane 的通用约定是 `Ctrl+W` 关闭窗口（视图发出 `CloseRequested`）；独立桌面便签是例外，由便签布局协调层把它解释为折叠当前项，走与纸片关闭相同的保存和折叠流程。管理器保持通用关闭行为。全局键用 Pane 现有注册和冲突处理，模块停用时释放。未核对的键位不猜默认值。 |
| 列表、搜索、分类 | 复用管理器列表和分类命令。以 ID 保持选择；标题、正文、分类以及显示状态变动只刷新相关项。分类内按最近修改排序；是否让已贴到桌面的项靠前，以对照 Galaxy 的结果为准。窗口置顶只是布局偏好：对未贴到桌面的便签设置时只保存，不开窗口。编辑当前项期间不重新排序，避免自动保存后条目在光标下跳到顶部；切换选中项或管理器失去焦点后再排序。行上显示「已隐藏」「已贴到桌面」和提醒标记，并可按「已隐藏」筛选。核对重命名、删除分类和移动后的筛选与选中状态。 |
| 导入 | 复用系统选择器及 `NoteStore.ReadFile` 的严格 UTF-8 读取、容量限制和换行规范。选择器和存储入口都拒绝非 `.txt`。以文件名为初始标题、正文来自文件，每次创建新 ID。选择器允许多选，每个文件各建一条；部分失败时成功的照常保留，结束后汇总失败的文件名及原因。取消、坏编码、越限和读写失败不留下空记录。源文件路径不进入便签模型。 |
| 另存和导出 | 系统保存对话框只提供 `.txt`，以便签标题建议文件名；无标题时取正文首个非空行，仍为空则用「未命名便签」。建议名替换 Windows 非法字符和保留名，去掉首尾空格与点并限制长度。写当前纯文本正文，不保存标题元数据。覆盖由保存对话框确认。复用 Pane 的路径限制及可用的安全替换写入方式；取消或写入失败不能改变源便签。用中文、空正文、换行和特殊文件名验收。 |

## 4. 历史、回收站、数据设置与备份

写盘和记历史分开。现有代码每次提交都把上一版写进历史（`CommitCore`），管理器自动保存间隔又只有 600 ms，连续输入一两分钟就会挤满 30 版上限，使历史失去作用。MVP 中自动保存只写当前正文；以下时机才把编辑前的内容记为一个历史版本：本次编辑会话第一次修改正文、距上次记录且停止输入超过数分钟、窗口关闭／折叠／切换便签、历史恢复之前。保留现有最近 30 版上限。同一正文重复保存，以及分类、窗口置顶或提醒的单独变化，不新增正文历史。恢复前先完成共享草稿保存，再复核历史页打开时对应的内容修订；期间内容变化则刷新确认，避免用过时的预览覆盖刚输入的字。恢复保留被替换内容作为历史，当前分类不被旧正文带回；成功后刷新所有编辑器和胶囊。

删除先结清草稿，再通过回收站移除列表项、桌面窗和胶囊，清除提醒；回收恢复还原文本、分类和历史，沿用 Pane 当前规则，不自动恢复提醒，也不自动重新贴到桌面。永久删除仍需确认，窗口状态变更只有在数据操作成功后才发布。

移入回收站后显示数秒的「撤销」提示。撤销时恢复正文、分类、提醒，以及删除前的贴到桌面状态和布局；超时后按上面的回收规则处理。为此删除时暂存该 ID 的布局快照，直到撤销期结束。

数据目录入口沿用 Pane 设置。若核对确认需要便签专属目录切换，复用现有数据路径管理：先保存并暂停便签写入，在目标验证新版本记录可读后再切换；失败时继续使用原目录。备份沿用 Pane 的选择性导入导出，核对正文、分类、历史与回收状态；数据路径、全局热键和显示器绑定是本机设置。新数据正常重启会恢复布局，与跨机器备份的范围分开。单条 TXT 导出不包含分类、提醒和历史。

## 5. 整条便签提醒

复用 Pane 的按 ID 持久化、单计时器调度、现有预设、自定义延迟和启动补发。管理器、桌面窗口和前述列表标记都读同一条提醒；新增或取消只走同一入口。无任务级提醒、日历选时、重复提醒或胶囊专用调度。

折叠、隐藏及换屏只改布局，提醒不受影响。到点用 Pane 现有弹窗。点击「打开」时，已贴到桌面的便签展开并聚焦其桌面窗口（包括从胶囊或隐藏状态展开）；未贴到桌面的才在管理器中按 ID 定位。设有提醒的胶囊显示提醒角标，到点时短暂高亮，不改变其展开状态和队列位置。便签移入回收站时取消提醒；调度读取时再次确认仍是有效便签，避免删除与到期同时发生时弹出失效记录。验证设置、修改、取消、到期、重启补发和删除。

## 6. 胶囊状态和窗口生命周期

每条便签分别保管：桌面是否显示、展开或折叠状态、展开形态（编辑窗或磁贴）、窗口置顶偏好、展开矩形、可选胶囊落点。落点包含显示器、左／右／顶部边缘或悬浮、位置及队列顺序。每个显示器的每条边另存队列起点、收放状态和滚动偏移。展开矩形与胶囊落点互不覆盖。列表标签由这些字段推导，避免出现两套状态。

| 操作 | 状态和窗口结果 |
| --- | --- |
| 贴到桌面／从列表找回 | 按 ID 创建或聚焦桌面便签，恢复展开矩形及形态；首次打开使用当前显示器的正常安全位置。 |
| 纸片关闭／`Ctrl+W` | 先提交共享草稿。首次选择当前屏幕工作区最近的左、右或顶部；后续复用胶囊落点。布局提交成功后结束正文窗口；失败保持原状态。 |
| 点击普通胶囊 | 打开或聚焦同 ID 的便签，恢复展开位置和尺寸，保留胶囊入口。再次点击聚焦，折叠由窗口命令显式触发。 |
| 单张胶囊关闭／隐藏菜单 | 保存后关闭正文窗口并从队列移除显示，保留正文、落点和窗口置顶偏好；托盘或管理器可找回。 |
| 主胶囊收放 | 只改变当前队列的显示状态，不改变成员的窗口状态。保留滚动位置，主胶囊始终可操作。 |
| 空的新便签关闭 | 按第 2 节规则直接丢弃，不生成胶囊。 |
| 模块停用／删除 | 停用释放窗口和事件并保留本机布局；删除清掉该 ID 的胶囊和布局，不误动同队其他成员。 |

**三种「关闭」要在界面上分开。** 纸片上的按钮是折叠，使用折叠图标，提示文字写「收成胶囊」，不用 ×；单张胶囊的隐藏放在右键菜单中，或使用带「隐藏」提示的独立图标；删除只在菜单中出现。首次折叠时播放窗口缩向目标边缘的过渡，并给一次性提示说明胶囊位置和找回方式。

**胶囊标签。** 显示标题；无标题时取正文首个非空行，仍为空则显示「未命名」。

普通编辑窗延用现有 Pane 桌面便签窗口。每条有内容的屏幕边复用一个队列宿主，共用一个悬停预览宿主；悬浮项单独承载。折叠项不保留正文窗口。队列输入区域只覆盖可见胶囊，裁切的元素及透明缝隙不拦截其他应用的点击。先核实现有玻璃窗命中区域能力；若不适合不规则队列，再补便签专用薄宿主。

## 7. 几何、拖动和全屏

**几何与停靠。** 抽取或复用 Pane 的显示器枚举、工作区、设备标识和 DPI 查询。布局用相对工作区的 DIP 保存；从屏幕物理坐标定位当前显示器，在宿主边界按目标屏 DPI 转换。纯布局逻辑计算最近边缘、顶部默认居中、左右纵排、顶部横排、视窗裁切、插入索引和预览矩形，可脱离真实窗口验证。处理负坐标、任务栏改变和跨屏混合 DPI。

**拖动与滚动。** 鼠标按下先记录候选成员、指针和原位置，超出阈值才捕获并进入拖动。沿队列方向给出插入位置；拖向目标边缘停靠，折叠项拖离可悬浮。展开后保留的入口可换边或换屏，先折叠才可拖成悬浮。主胶囊沿边拖动改队列起点，跨边或跨屏拖动移动整队；提交时重新检查成员，已隐藏或删除的项跳过。松手才提交布局，取消、丢捕获、显示配置变化恢复旧布局，无意外点击。溢出滚动只移动成员区，顶部接受横向滚动与普通鼠标滚轮。

**悬停。** 普通胶囊延迟打开只读纯文本预览，左右向屏内、顶部向下，约束在工作区内。胶囊、预览和两者间的窄通道组成一块连续的悬停区域；移入预览可滚动，不取得键盘焦点。开始拖动、离开区域或切至全屏时关闭预览。截断的标题仍可通过预览及辅助技术读到。

**顶部队列。** 顶部胶囊会盖住最大化窗口的标签页和标题栏按钮。顶部队列默认使用更窄的形态，悬停时再展开为完整胶囊；对照时核实 Galaxy 的处理方式，并验收最大化浏览器和资源管理器的顶部操作不受影响。

**键盘访问。** 提供一个快捷键打开「桌面便签」弹层，列出所有贴到桌面的便签（含已隐藏），可用方向键选择、回车展开、Esc 关闭；胶囊本身不进入其他应用的 Tab 顺序。默认键位与第 3 节快捷键一并核对。

**全屏与恢复。** 使用 Pane 现有 Win32 窗口层控制；如果桌面宿主没有可复用的全屏信号，补一个由便签模块拥有的前景窗口观察者。辨别可见的外部前景窗口、窗口覆盖的显示器及完整屏幕矩形；过滤 Pane 自己、桌面和最小化窗。只改变该屏便签窗口的临时层级，确保位于外部全屏窗之后，其他屏保留原状态。范围包括胶囊、悬停预览，以及打开了窗口置顶的已展开便签；用户在全屏期间主动展开的便签除外。退出全屏后恢复，始终不改写窗口置顶偏好。只有用户主动展开才聚焦正文窗。

**重启和屏幕变化。** 按屏幕身份恢复展开矩形、单张落点、队列顺序、收放和滚动；缺失屏幕回退到可用屏幕并夹紧到工作区，滚动偏移也按实际内容限幅。拖动预览不逐帧写设置；落点、收放、滚动结束后提交。重启只实例化当前可见的宿主，隐藏项仍能从列表找回。

## 8. 实施顺序和验收

| 顺序 | 检查点 | 通过条件 |
| --- | --- | --- |
| 1 | 纯文本、共享草稿和文件 | 交替在两个窗输入、输入法组合、自动保存延迟和写入失败；TXT 导入（含多选和部分失败）创建新条目，导出后可重导，源文件不变；无标题和特殊标题的建议文件名可用；连续输入数分钟后历史仍保留更早的版本；空的新便签关闭后不留记录。 |
| 2 | 入口、列表、历史和提醒 | 对照启动入口、按键和作用域；历史恢复即时同步；回收和取消提醒不留下胶囊或无效弹窗；删除后撤销能恢复桌面位置；提醒「打开」按贴到桌面与否到达正确位置；编辑时列表不跳动；已隐藏标签和筛选可用。 |
| 3 | 胶囊状态和几何 | 检查展开与折叠、失败不关窗、隐藏找回、三边布局、悬浮、溢出、重排、整队迁移及启动读取；确认折叠后无正文窗口残留；三种关闭的图标和提示可区分，首次折叠有提示；键盘弹层可找回所有桌面便签。 |
| 4 | 真实 Windows 交互 | 用开发构建（JIT）实际点按、拖动、滚轮和触控板，覆盖双屏混合 DPI、断屏、全屏进出（含置顶的展开便签）、重启，胶囊透明间隙可点穿，以及顶部队列不妨碍最大化窗口的标题栏操作。记录 Galaxy 和 Pane 的入口、动作及结果。 |
| 5 | 同一交付包回归 | 使用新测试数据，验证 NativeAOT 发布构建和便签备份恢复；另用一份含旧图片、Markdown 记录和任务提醒的原有目录，确认按第 1 节规则读取。一个版本通过上述全部检查才满足 MVP。 |

优先复用现有便签历史、备份和桌面排位回归；需要新增自动验证时，重点覆盖共享草稿保存顺序、状态转换和几何边界。无界面验证不能代替真实全屏层级、焦点和跨屏拖动验收。
