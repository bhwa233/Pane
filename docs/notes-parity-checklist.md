# Pane 便签功能对齐清单

逐项实现设计、失败处理和验收见 [Pane 便签 MVP 技术方案](notes-mvp-technical-design.md)。

对照版本：本机 Galaxy Tools `main`（`6156e93`）。MVP 在纯文本范围内对齐便签的入口、快捷键和操作结果，保留 Pane 的视觉风格。文件操作只支持 `.txt`；导入会创建独立的新便签。MVP 不支持图片，不要求兼容或迁移旧便签、附件、历史及桌面布局，也不与 Galaxy 共用或同步数据。

「贴到桌面」「窗口置顶」与列表排序的区别见技术方案的术语说明。

本清单来自源码初查，尚未逐项手测。「待补齐」表示已有明确的功能差异；「待核对」表示 Pane 已有相关能力或原版细节尚未确认，实测一致即可勾选，无需重做。

## 待调整与补齐

| 待办 | 功能 | 验收结果 |
| --- | --- | --- |
| [ ] | 只保留纯文本 | 移除 Markdown 模式、格式工具栏、分栏与渲染预览、任务勾选与任务提醒，以及 `.md` 文件操作入口。便签、桌面、胶囊和历史均不提供图片添加、粘贴或查看。整条便签提醒保留。 |
| [ ] | 导入 TXT 为新便签 | 选择 `.txt` 后创建独立的新便签；取消不创建记录。修改新便签不写回源文件，也不保留文件关联或监听外部改动。 |
| [ ] | 实时同步同一份草稿 | 管理器和桌面窗口按便签 ID 共用一份草稿及一套自动保存。任一处输入后，另一处立即更新；不必等写盘即可切到另一处继续编辑。验证在两处轮流输入、折叠再展开、关闭或切换便签时不丢字。 |
| [ ] | 历史不被自动保存冲掉 | 自动保存只写当前正文；历史只在首次修改、停顿数分钟、关闭／折叠／切换和恢复前记一版。连续输入数分钟后，历史里仍能找到编辑前的版本。 |
| [ ] | 空便签不留痕 | 新建后标题和正文都为空就关闭、折叠或切走，不留记录、胶囊或布局。 |
| [ ] | 删除可撤销 | 删除后显示数秒的「撤销」提示；撤销恢复正文、分类、提醒，以及原来的贴到桌面状态和位置。 |

## 待核对，按实际差异补齐

| 待办 | 功能 | 对照重点 |
| --- | --- | --- |
| [ ] | 打开与快捷键 | 管理器、快速新建和桌面便签的入口；记录原版的默认键、可配置项和作用范围（全局、窗口或编辑器），再核对焦点和重复触发行为。确认快速新建的落点只有一处（新桌面便签或管理器新条目）。 |
| [ ] | 列表与分类 | 新建、搜索、排序、筛选，分类新增、改名、删除和移动。核对右键菜单、贴到桌面与提醒标记、删除当前项后选中哪一条。编辑当前项时列表不跳动；行上显示「已隐藏」标签，并可按其筛选。 |
| [ ] | 桌面便签状态 | 逐项核对贴到桌面、磁贴与编辑窗切换、窗口置顶及隐藏；同时确认 Galaxy 是否有独立的列表置顶。列表状态与桌面同步，贴到桌面、窗口置顶与当前是否显示分别处理。 |
| [ ] | 纯文本编辑器 | 核对选区、光标、换行、复制粘贴、撤销重做和自动保存；输入 Markdown 符号时按原样显示和保存。 |
| [ ] | TXT 另存与导出 | 检查只生成 `.txt`，并验证文件名、覆盖确认、UTF-8 内容、取消和重新导入。无标题时用正文首行或「未命名便签」建议文件名，非法字符被替换。导入支持多选，部分失败时汇总原因。 |
| [ ] | 历史、删除与恢复 | 核对 MVP 内新建便签的历史入口、纯文本预览、保留策略和恢复行为；恢复前处理共享草稿，恢复后各窗口显示同一内容。核对删除确认及恢复后的正文、分类、提醒和桌面状态。 |
| [ ] | 便签设置与数据位置 | 核对原版便签专属设置、目录查看或更改入口，以及 Pane 对 MVP 数据的备份与恢复。目录调整只涉及 Pane 自己的数据。 |

## 整条便签提醒：复用 Pane 现有能力

- [ ] **沿用现有提醒。** 管理器和桌面便签按同一个便签 ID 读写提醒，继续使用 Pane 的预设时间、自定义延迟、到点弹窗和启动后补发。不新增独立的胶囊调度，也不为对齐 Galaxy 新增日历选时或重复提醒。
- [ ] **对接胶囊。** 折叠、隐藏或换屏均不影响已设提醒；删除便签时清除。到点后点击弹窗的「打开」：已贴到桌面的便签展开其桌面窗口，否则在管理器中定位。设有提醒的胶囊显示角标，到点时短暂高亮。
- [ ] **只提供整条便签提醒。** 移除 Markdown 任务提醒。手测：设提醒 → 折叠或隐藏 → 到点弹窗 → 点击打开并到达原便签（桌面窗口或管理器）；另核对重启补发和删除后不再提醒。

## 胶囊系统：MVP 必须完整交付

Pane 已有桌面磁贴和编辑窗切换；Galaxy 另有独立的贴边及悬浮胶囊。下列各项均须随同一个 MVP 版本交付并通过验收，不拆到后续版本。沿用 Pane 外观，悬停只预览纯文本。行为参照 Galaxy 的本地文档 `Docs/edge-capsules.md`。

- [ ] **折叠与展开。** 关闭按钮和 `Ctrl+W` 折叠便签；先保存，失败则保留编辑窗。点击胶囊恢复原窗口位置和尺寸，入口保留，再点可找回或聚焦窗口。胶囊和编辑窗共用同一条便签。折叠按钮用折叠图标而非 ×，与隐藏、删除在界面上可区分；首次折叠有缩向边缘的过渡和一次性提示。无标题便签的胶囊显示正文首行或「未命名」。
- [ ] **隐藏与找回。** 单张胶囊的隐藏按钮（带「隐藏」提示）及右键菜单可隐藏该便签，保留正文和窗口置顶偏好；可从托盘（含「显示全部桌面便签」）、便签列表或键盘弹层找回。整队收起仍保留主胶囊。
- [ ] **停靠与悬浮。** 首次折叠停到当前屏幕最近的左、右或顶部工作区边缘，避开任务栏。支持拖离后悬浮、换边、跨屏停靠和右键移到指定边缘；拖动结束或取消不误触展开。
- [ ] **主胶囊与队列。** 各屏各边独立排列，主胶囊显示数量并控制整队收放，可调起始位置或整队换边、换屏。单张可重排；队列溢出时能滚动，主胶囊仍可操作，空白不挡桌面点击。顶部队列默认较窄、悬停展开，不妨碍最大化窗口的标签页和标题栏按钮。
- [ ] **悬停与全屏。** 悬停显示不抢焦点的只读纯文本预览，可移入滚动；顶部向下展开，左右向屏幕内侧展开。外部应用在对应屏幕全屏时，胶囊、预览和打开了窗口置顶的展开便签都让到其后，退出全屏后恢复，便签自己的窗口置顶偏好保持原值。
- [ ] **键盘访问。** 快捷键打开「桌面便签」弹层，列出所有贴到桌面的便签（含已隐藏），方向键选择、回车展开、Esc 关闭。
- [ ] **重启与显示器变化。** 恢复便签的展开、折叠、隐藏、贴边或悬浮状态，以及所在屏幕、边缘、顺序、收放、位置和滚动进度。手测跨屏拖动、不同 DPI、屏幕拔除和真实全屏，确保仍能找回便签。

## 建议的手测顺序

以下是同一 MVP 的分步验收顺序，不是分批交付计划。胶囊的跨屏拖动、队列重排、全屏避让和重启恢复均纳入本次验收。

1. **先测桌面和保存。** 新建便签 → 贴到桌面 → 两处编辑同一条 → 收成胶囊再展开 → 重启 → 恢复历史。核对窗口与数据分别恢复到了什么状态。
2. **再测纯文本与文件。** 用含中文、换行和 Markdown 符号的临时 TXT 验证导入为新便签、编辑后源文件不变、另存和历史恢复。确认没有图片、Markdown 模式和 `.md` 文件入口。
3. **最后补齐入口和边界。** 逐项记录 Galaxy 与 Pane 的入口、实际按键、作用范围、结果及差异，再验收通知、文件取消和写入失败。以实际 Windows 操作结果勾选。
