# Galaxy Tools → Pane：性能验证与迁移待办

## 2026-11-18 Windows 实测

| 场景 | Galaxy 0.1.7 | Pane NativeAOT 原型 | 减少 |
| --- | ---: | ---: | ---: |
| 三卡常驻、卡片桌面收起 | 553.2 MiB | 132.9 MiB | 420.3 MiB（76.0%） |
| 卡片桌面展开 | 526.7 MiB | 142.4 MiB | 384.3 MiB（73.0%） |
| 热切换 24 次后收起 | 538.1 MiB | 151.7 MiB | 386.4 MiB（71.8%） |

上表为整组私有工作集（实际驻留内存）中位数，包含宿主进程树、流量桥和共享 ETW 服务；独立文件索引、DWM、GPU 显存不计入。私有提交量在三个阶段分别为 Galaxy 849.4 / 819.5 / 828.4 MiB、Pane 200.9 / 210.2 / 219.4 MiB。两边顺序运行，各阶段的采样跨度约 28–31 秒，并分别完成 24 次开关循环。

同一台 16 逻辑处理器的 Windows 机器、同一个显示工作区、同一套隔离夹具（流量 HUD、测试便签、同一张 672 × 517 PNG）。Galaxy 使用已安装的正式包及其实际卡片层；Pane 保留正常启动与托盘路径，额外启动开发构建专用的原生探针。两边计入同一个 `spark233Traffic` 服务，流量桥版本为 0.2.7。Pane 在 `own` 范围按 1 秒调用真实 ETW 快照，最终记录 120 次采样，质量为 `good`。没有停止用户正在运行的软件或更换 ETW 服务。

## 判定与限制

- **内存门槛已达到。** 三种状态都超过减少 100 MiB 且 30% 的门槛。剔除共享服务后，常驻宿主（包含流量桥）是 524.5 → 91.4 MiB，说明收益不是由共享服务变小造成的。
- **Pane 热切换后宿主占用接近稳定。** 宿主和流量桥合计中位数 91.4 → 93.4 MiB；整组 132.9 → 151.7 MiB 的增长主要来自共享服务在该轮采样中从 38.2 → 57.8 MiB。24 次切换不足以排除长期泄漏。
- **CPU 尚未达到正式验收口径。** 整组 CPU 占整机比例，Galaxy / Pane 展开时为 0.76% / 0.37%，热循环后为 0.67% / 0.25%；启动约 6 秒后开始的首段常驻采样为 0.88% / 1.79%。重算 Pane 首段的已计入增量：主进程 1.446%，共享 ETW 服务 0.337%，桥接进程 0.007%，即峰值主要来自主进程，不能归因于子进程。原始汇总只累计相邻采样均存在的进程增量，可能漏掉短命进程和观测窗口之前的 CPU，不能用来计冷启动。
- **耗时不做横向承诺。** Galaxy 记录宿主调用到观察到桌面栏 DOM 的 P95；Pane 记录 UI 线程处理请求到合成回调的 P95。起止点不同，不用二者差值宣称提速。正式首版使用相同的触发与可见帧判定。
- **这是原型实测，不是功能等价认证。** Pane 用同一个 WinUI 窗口承载三张最小卡片，未实现 Galaxy 的多窗口外观、卡片交互、网卡采样管线、进程排行/图标和历史查询等。结果足够支持启动首版试迁，但不能承诺全部功能迁完仍省同样多。

### 2026-11-20 网卡采样局部测量

同一 Windows 机器上，旧 Pane 的逻辑枚举到 40 个符合条件的接口候选；新 DLL 返回 1 张活动物理网卡，GUID 和索引与 `Get-NetAdapter -Physical -IncludeHidden` 一致，间隔约一秒的两次读数单调。用同一进程执行三轮交替查询，每轮每种实现预热 20 次并测 200 次，单次中位数从 **28.13–28.57 ms** 降到 **1.81–1.84 ms**。测量包含旧 Pane 的接口枚举、字节计数读取和字典构造，以及新 Pane 的一次原生接口表采集；不包含 Pane 面板、速率计算、ETW 或 Galaxy 进程，不将结果外推为整机 CPU、内存或最终迁移收益。

### 正式服务的对照口径

2026-11-20 进程清单刷新仍用 Windows 进程句柄核对创建时间，匹配同一实例且路径和账号均已读取时，不再重复读取这两项；实时事件在已排序的 PID 实例内直接查找，不再逐事件筛选和排序。同机交替比较优化前的内测包与优化后的 x64 Release 服务核心，每侧 3 个独立进程。清单刷新 48 点中位数从 **24.84 ms 降到 12.06 ms（减少 51.5%）**，单次托管分配从 **42.60 MiB 降到 2.17 MiB（减少 94.9%）**。80,000 条合成事件的聚合耗时中位数从 **58.55 ms 降到 46.52 ms（减少 20.6%）**，每侧 21 点。两份核心均通过真实测试进程启动、退出和身份补全，以及合成 PID 复用边界、账号分隔、聚合与 SQLite 落盘结果校验。数据、组件哈希及清单探针在 `C:/temp/PaneTrafficCatalog-86d3a92d/`。优化随后纳入 [当前隔离内测包](pane-migration-plan.md#61-terra-验收交接)；从该包提取的流量程序集另行通过功能验证，不用于上述性能数字。未注册 Pane 服务、未跑实时 ETW 或界面；这些是局部耗时和分配，不是常驻内存或 Pane 对 Galaxy 的整组节省。
